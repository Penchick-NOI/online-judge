# PNOI organiser guides

These guides are for PNOI organisers who need to set up problems and contests on the site. They assume you have
never used DMOJ (the software PNOI is built on) before.

- [Adding a problem](adding-a-problem.md): create a problem in the admin pages and upload its test data.
- [Running a contest](running-a-contest.md): create a contest, see what participants see, and rate the contest
  afterwards.
- [Organizations: approving requests](organizations.md): approve or reject students' requests to start an
  organization.

You need an account with staff access to follow these guides. If you are logged in and click your picture at the
bottom of the menu on the left, staff accounts see an **Admin** link. If you do not see it, ask a site administrator to give your
account staff access and the permissions for problems and contests.

## How these guides were checked

Both guides were followed from start to finish on a working copy of PNOI with a real judge on 16 November 2026: a
problem was created and given test data with a batch, solutions in C++17, C++20 and Python 3 were judged, a rated
contest was created, joined by two test accounts, and rated. Parts that were **not** tried: batch dependencies,
generator files, the float and other special checkers, pretests, access codes and the other **Access** fields,
spectating, virtual joins, and **Rate all ratable contests**.
